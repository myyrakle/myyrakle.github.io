[RouterOS] IP 관리 기본

#네트워크/웹

RouterOS는 UI 기반 콘솔도 잘 지원하지만, 설정작업들은 CLI로 하는 것이 편리하다.
CLI 명령 위주로 해서, IP 추가, IP 고정, 포트포워딩 정도의 일반적인 작업만 정리한다.




WAN 추가

회선에 IP 여유분이 있다면, 요청하는 만큼 추가 IP를 받아올 수 있다.
그러려면 인터페이스와 DHCP Client를 할당해주면 된다.

/interface/macvlan add name=wan이름 interface=ether1 mode=private
/ip/dhcp-client add interface=wan이름 add-default-route=no use-peer-dns=no disabled=no

WAN - IP 목록은 다음 명령으로 확인할 수 있다.

/ip dhcp-client print detail

UI에서는 IP - DHCP client 탭에서 확인 가능




포트포워딩하기

방화벽/NAT 수준에서 제어한다.
다음과 같이 설정할 수 있다.

/ip/firewall/nat
add chain=dstnat \
    in-interface=나갈인터페이스 \
    protocol=tcp \
    dst-port=외부포트 \
    action=dst-nat \
    to-addresses=내부주소 \
    to-ports=내부포트 \
    comment="port forwarding"

추가하면 이렇게 행이 추가되고, 외부접속도 바로 열릴 것이다.



포트포워딩 - 헤어핀

근데 저렇게 하면 외부에서 접속하는건 되는데, 내부에서 외부 IP로 접속하는건 또 안된다.
이걸 허용해주려면 이른바 "헤어핀"이라고 하는 접속 경로를 뚫어줘야 한다.

어렵진 않다. 다음과 같이 리소스 2개만 추가해주면 된다.

/ip firewall nat
add chain=dstnat src-address=192.168.88.0/24 dst-address-type=local protocol=tcp dst-port=내부포트 \
    action=dst-nat to-addresses=내부IP to-ports=외부포트 \
    comment="wan-proxy hairpin dstnat" place-before=[find comment="wan-proxy inbound"]
add chain=srcnat src-address=192.168.88.0/24 dst-address=내부IP protocol=tcp dst-port=내부포트 \
    action=masquerade comment="wan-proxy hairpin srcnat"



DHCP 관리 - 내부 IP 고정 & 변경

서버로 사용되는 장비가 있다면 내부 IP의 관리도 중요해진다.
결국 내부 IP를 통해서 내부 통신이나 포트포워딩 등이 이뤄지는 것이기 때문이다.

DHCP Server / Lease 탭에서 조정 가능하다.

먼저 Make Static 버튼을 눌러서 해당 맥주소의 Lease를 고정한다.

그리고 Lease 상세에 들어가서 주소를 임의로 변경하면 끝이다.

간단하다.




DHCP - 자동 할당 범위 제어

라우터를 여러 용도로 사용한다면 내부 주소 할당 규칙을 바꾸고 싶을 수 있다. 따로 설정하지 않는다면 전체 IP 목록에서 라우터가 랜덤으로 배정을 해주기 때문이다.

특정 주소 영역을 미리 예약해두려면, Pool 설정에 들어가서 범위를 조절해주면 된다.

쉽다.
